# 형식 변환기

## 이런 걸 할 수 있어요

- **형식 변환**: `a,b,c` 같은 데이터를 `c-b-a`처럼 원하는 모양으로 바꿔요. 변수를 기준으로 정렬하거나 숫자만 뽑아 쓸 수도 있어요.
- **케이스 변환**: 한글 이름과 영어 단어를 `TABLE_NAME`, `TableName`, `tableName`, `table_name`으로 한 번에 바꾸고, 원하는 형식으로 복사해요.
- **목록 합치기**: 여러 목록을 같은 순서끼리 짝지어 `id: 1`처럼 이어 붙여요.
- **줄·열 재배열**: 여러 줄로 묶인 데이터를 열 단위로 모아 다시 배열해요.
- **찾기·바꾸기**: `{변수}`가 들어간 패턴으로 찾아서, 규칙 여러 개를 차례로 바꿔요. 줄 조건으로 바꿀 범위를 좁힐 수도 있어요.
- **중복값 찾기**: 목록에서 같은 값을 모아 보여주고, 하나만 남기거나 삭제해요.
- **쿼리 작성**: SELECT·INSERT·UPDATE·DELETE·MERGE 틀을 자동으로 쓰고, DB별 문법과 컬럼 한글 주석을 넣어요.
- **목데이터 생성**: 컬럼마다 값 종류를 정해 테스트 데이터를 만들고, INSERT·UPDATE나 원하는 코드 형식으로 뽑아요.

반복되는 텍스트 가공 작업을 빠르게 처리하는 개발 보조 도구 모음이에요.
`index.html` 파일 하나로 동작하고, 설치나 서버 없이 브라우저에서 열면 바로 쓸 수 있어요.

## 시작하기

1. `index.html`을 크롬·엣지 같은 최신 브라우저에서 엽니다.
2. 홈 화면의 카드를 누르거나 주소창에 기능 이름을 입력해 기능을 엽니다.

- 빌드, 패키지 설치, 서버가 필요 없어요.
- 글꼴(IBM Plex Sans KR, Nanum Gothic Coding)은 Google Fonts에서 불러와요. 인터넷이 없으면 시스템 글꼴로 대신 보여요.
- 컴퓨터 브라우저에서 쓰는 것을 기준으로 만들었어요.

## 화면 구성

브라우저처럼 **탭 · 주소창 · 즐겨찾기 줄**이 있고, 기능마다 독립된 페이지로 열려요.

- 같은 기능을 여러 번 열어도 페이지마다 입력한 내용이 따로 남아요.
- 주소창에는 한글, 영어, 초성으로 입력해도 열려요. 예: `케이스`, `merge`, `ㅈㅂㄱ`
- 별(★)을 누르면 자주 쓰는 기능이 즐겨찾기 줄에 모여요.
- 뒤로·앞으로·홈 단추로 이동하고, 탭마다 기록은 최대 30개까지 남아요.
- 시스템 설정에 맞춰 라이트·다크 모드가 자동으로 바뀌어요.

### 단축키

| 동작 | 키 |
| --- | --- |
| 주소창으로 이동 | `Ctrl`(⌘) + `K` |
| 카드·즐겨찾기를 새 탭에서 열기 | `Ctrl`(⌘) + 클릭, 또는 마우스 가운데 단추 |
| 주소창에서 새 탭으로 열기 | `Alt` + `Enter` |

| 탭 이동 | `←` `→` `Home` `End` |

## 기능

### 1. 형식 변환
입력 형식에서 변수를 읽어 원하는 출력 형식으로 바꿔요.

- 입력 형식 `a,b,c` 또는 `{A} AS {B}` 처럼 변수 이름을 적습니다. `{ }`가 하나라도 있으면 중괄호 안만 변수로 읽어요.
- 형식을 여러 줄로 쓰면 데이터도 그 줄 수만큼 묶어서 한 건으로 읽어요.
- 출력 구분자는 `\n`, `\t`를 쓸 수 있고, 빠른 선택 칩도 있어요.
- 변수 하나를 기준으로 오름차순·내림차순 정렬할 수 있어요.
- **숫자만 받는 변수**: `{n:숫자}`로 쓰면 숫자만 읽어요. 예: 입력 `{n:숫자}id`, 출력 `id{n}` → `1id`는 `id1`

### 2. 케이스 변환
한글·영어 단어를 네 가지 케이스로 한 번에 보여줘요.

- 항목 형식은 `{한글} {영어}`처럼 정하고, 항목 구분자도 바꿀 수 있어요.
- 어퍼케이스(`TABLE_NAME`), 파스칼케이스(`TableName`), 카멜케이스(`tableName`), 스네이크케이스(`table_name`)로 변환해요.
- 값을 누르면 복사되고, 더블클릭(또는 `F2`)하면 직접 고칠 수 있어요.
- 열 머리글을 드래그해서 열 순서를 바꿀 수 있어요.
- `{어퍼케이스}, {파스칼케이스} AS {한글명}` 같은 복사 형식으로 전체·선택 항목을 한 번에 복사해요.
- 전체 보기에서 검색하고 북마크할 수 있어요.

### 3. 목록 합치기
여러 목록을 같은 순서끼리 짝지어 출력 형식대로 이어 붙여요.

- 목록은 2개에서 26개까지 늘릴 수 있고, 제목을 더블클릭하면 이름을 바꿔요. 이름을 바꾸면 출력 형식의 변수도 함께 바뀌어요.
- 목록 제목줄을 드래그해서 순서를 바꿀 수 있어요.
- 출력 형식 예: `{A}: {B}` (`{번호}`도 쓸 수 있어요)
- 줄 수가 다를 때 처리 방식을 고를 수 있어요: 긴 쪽에 맞춰 빈 값으로 채우기 / 긴 쪽에 맞춰 반복으로 채우기 / 짧은 쪽에 맞추기

### 4. 줄·열 재배열
N줄씩 묶인 데이터를 열 단위로 모아 다시 배열해요.

- 묶음 줄 수(1~20)와, 줄마다 항목 구분자·출력 구분자를 따로 정해요.
- **열끼리 모아 재배열**: `{1}`은 묶음의 첫째 줄, `{2}`는 둘째 줄 … 값으로 출력 형식을 만들어요.
- **줄마다 따로 변환**: 줄마다 자기 구분자로 쪼개서 자기 출력 구분자로 다시 이어 붙여요.

### 5. 찾기·바꾸기
`{변수}`가 들어간 패턴으로 찾고, 찾은 값을 바꿀 내용에 넣어 바꿔요.

- 찾을 내용 `안녕하세요 {a} 입니다.`, 바꿀 내용 `안녕하세요 {a}님.` 처럼 써요.
- `{n:숫자}`로 숫자만 받는 변수를 쓸 수 있어요.
- 규칙을 여러 개 만들어 두고 앞에서부터 차례로 적용할 수 있어요. 규칙마다 사용 여부와 순서를 바꿀 수 있어요.
- 줄 조건(포함·시작·끝, 그 반대 조건)을 여러 개 걸 수 있고, 조건이 여럿이면 모두 맞는 줄만 또는 하나라도 맞는 줄만 고를 수 있어요.
- 찾은 결과마다 체크로 바꿀 곳을 고르거나, 행의 `적용` 단추로 한 곳만 바로 바꿔요.
- 바꾼 결과는 먼저 아래에 보여주고, `원본에 적용`을 눌러야 원본이 바뀌어요. 되돌리기는 최대 30번이에요.

### 6. 중복값 찾기
목록에서 같은 값을 모아 보여줘요.

- 항목 구분자, 앞뒤 공백 무시, 대소문자 구분을 정할 수 있어요.
- 중복 제거(하나만 남기기), 중복값 전체 삭제, 선택 삭제를 지원해요.
- 표에서 값을 바로 고칠 수 있고, 되돌리기도 돼요.

### 7. 쿼리 작성
DML 구문 틀을 자동으로 써 주고, DB별 문법을 한글 설명과 함께 쿼리에 추가해요.

- DB 종류: Oracle, MySQL·MariaDB, PostgreSQL, SQL Server
- SELECT, INSERT, UPDATE, DELETE, MERGE(MySQL·PostgreSQL은 UPSERT) 구문 틀을 넣어요.
- **테이블·컬럼 등록**에서 테이블명, 컬럼명, 한글명, 키 컬럼을 등록하면 한글명이 주석으로 달리고, 키 컬럼이 UPDATE·DELETE의 WHERE에 들어가요.
- 주석 형식은 `--`, `/* */`, `#`(MySQL만) 중에서 골라요.
- 문법 목록을 한 번 누르면 설명이 보이고, 한 번 더 누르면 쿼리에 추가돼요.

### 8. 목데이터 생성
컬럼마다 값 종류를 정해 테스트용 데이터를 만들고, INSERT·UPDATE 또는 원하는 코드 형식으로 뽑아요.

- 최대 1000건까지 만들 수 있고, DB 종류에 맞는 날짜 함수·형식으로 나와요.
- 값 종류: 값 목록에서 랜덤 / 값 목록 순서대로 / 고정값 / 순번 / 정수·소수 범위 / 날짜·일시 범위 / 현재 일시 / 오늘 날짜 / 한글·영문 이름 / 전화번호 / 이메일 / SQL 식 직접 입력 / NULL
- 랜덤 값은 `중복 없이` 옵션으로 겹치지 않게 만들 수 있어요.
- 출력은 INSERT, UPDATE, 사용자 지정 형식 중에서 고르고, 한글 주석과 값 양옆 따옴표를 켜고 끌 수 있어요.
- 사용자 지정 형식 변수: `{번호}` `{테이블}` `{컬럼}` `{카멜}` `{한글명}` `{값}` `{SQL값}`
  예: `map{번호}.put("{카멜}", "{값}"); // {한글명}`
- 쿼리 작성 탭에서 등록한 테이블을 불러올 수 있어요.

#### 여러 줄 붙여넣기

한 줄에 `컬럼명 한글명 종류코드 설정` 순서로 써서 컬럼을 한꺼번에 추가해요. 화면의 `입력 가이드`에서도 볼 수 있어요.

```text
USER_ID 사용자ID s 1,1,5
USER_NM 사용자명 kn
AGE 나이 i 20,60
GRADE 등급 p A,B,C
REG_DT 등록일자 d 2026-01-01,2026-12-31 YYYYMMDD
```

| 종류 | 코드 |
| --- | --- |
| 값 목록에서 랜덤 / 순서대로 | `p` / `c` |
| 고정값 (`{n}`은 번호) | `f` |
| 순번 (시작,증가,자릿수) | `s` |
| 정수 / 소수 | `i` / `dec` |
| 날짜 / 일시 | `d` / `dt` |
| 현재 일시 / 오늘 | `now` / `today` |
| 한글 이름 / 영문 이름 | `kn` / `en` |
| 전화번호 / 이메일 | `ph` / `em` |
| SQL 식 / NULL | `raw` / `null` |

값 목록 안에 쉼표가 들어가면 `\,`로 써요. 한글명에 `c`, `d` 같은 영문 한 글자가 따로 있으면 코드로 읽히니, 한글명을 큰따옴표로 감싸세요.

## 저장되는 것

입력한 데이터는 따로 저장하지 않아서 **새로고침하면 처음 상태로 돌아와요.** 브라우저(localStorage)에 남는 것은 아래 세 가지뿐이에요.

| 키 | 내용 |
| --- | --- |
| `fx.marks` | 즐겨찾기 |
| `fx.qb` | 쿼리 작성·목데이터 탭에 등록한 테이블·컬럼 |
| `fx.qb.db` | 마지막으로 고른 DB 종류 |

## 개발 메모

- 외부 라이브러리 없이 HTML, CSS, JavaScript만 써요.
- `index.html`은 브라우저 틀(탭·주소창·즐겨찾기)이고, 각 기능 화면은 파일 안의 `TOOL_SRC` 문자열에 들어 있어요. 기능을 열 때마다 이 문자열로 iframe을 만들기 때문에 페이지별 입력이 따로 유지돼요.
- `TOOL_SRC`는 JavaScript 문자열 안의 코드라서, 코드를 고칠 때 역슬래시(`\`)와 `<` 문자의 이스케이프에 주의해야 해요. 문자열 속 정규식은 `\\`, 그 안의 문자열 상수는 `\\\\`처럼 겹쳐서 써야 하고, `<`는 `\u003c`로 적혀 있어요.
- 새 기능을 추가하려면 `TOOLS` 배열에 항목을 추가하고, `TOOL_SRC` 안에 탭 버튼과 패널(`p-기능키`)을 만들면 돼요.
